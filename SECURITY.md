# Reporting security concerns

Report issues with the repair tools or published artifacts through this repository's private vulnerability reporting feature when enabled. For an ordinary crash, use the bug report form.

Do not attach account credentials, verification codes, Bluetooth authentication identifiers, signing keys, full device bugreports, or unredacted logs to a public issue. The useful minimum is the app/release version, phone model, Android version, glasses model, failing action, and a short redacted exception stack.

The patched app retains the original vendor's account requirements and network behavior. LensFix's successful crash test is not an audit of the vendor app or its services.
